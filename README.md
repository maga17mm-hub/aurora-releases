# Aurora

Приложение для общения с друзьями для Windows x64.

[Скачать последнюю версию](https://github.com/maga17mm-hub/aurora-releases/releases/latest)

Впервые скачайте Aurora-Setup-…-x64.exe и установите поверх прежней версии. Начиная с 0.8.0 Aurora сама проверяет этот репозиторий при запуске, показывает новую версию и предлагает загрузку и установку по кнопке. Перезапуск доступен после завершения звонка. Профиль и переписка используют прежний каталог данных.

Звонки пока требуют общей сети Radmin VPN. Звук компьютера при демонстрации включается отдельно; передаётся звук всех приложений, кроме Aurora. Для него всем участникам нужна 0.8.0 или новее.

Установщик без цифровой подписи издателя; контрольная сумма SHA-256 приложена к каждому выпуску. Здесь размещены только файлы выпусков и описания: пользовательские профили, переписки и ключи не публикуются.
